# Win+Space Quick-Capture Overlay — spec

Goal: press **Win+Space anywhere in Windows** → tiny always-on-top bar →
type or hold-to-talk → `Enter` → task(s) appear in the main UI instantly.

## UX
- Global shortcut `Super+Space` summons; `Esc` dismisses; `Enter` submits.
- Two modes in one bar: **type** (default focus) + **hold `V` or mic button**
  for a ≤30s Deepgram streaming burst (same pipeline, short session).
- Submit → `POST /api/capture {text}` → toast-less micro-confirm
  ("+2 tasks · Browser Automation") → auto-dismiss 900ms.
- Offline-safe: if backend is down, queue to `%APPDATA%/tasker/outbox.json`.

## Implementation: Tauri (preferred)
- Rust side: `tauri-plugin-global-shortcut` registers `Super+Space`;
  window = `always_on_top + transparent + decorations(false)`,
  sized ~640×120, centered-top.
- Frontend: single HTML input + `<VoiceVisualizer mode="orb"/>` mini.
- Mic: `navigator.mediaDevices.getUserMedia` in the overlay webview;
  PCM frames POSTed/streamed to backend `/ws` (backend owns Deepgram key —
  keys never ship in the overlay).
- Autostart on login via Tauri autostart plugin.

## Fallback: Electron
Same UX; `globalShortcut.register("Super+Space", …)`. Heavier download,
so Tauri stays the default. Shared `ui/overlay/frontend/` for both shells.

## Security notes
- Overlay talks to `http://127.0.0.1:8765` with a local token from `.env`
  (`OVERLAY_TOKEN`, generated by wizard in Phase 2).
- No API keys bundled; no cloud round-trip except backend's own providers.
